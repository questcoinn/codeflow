## [장애 보고] 11/18(수) 결제 페이지 오류로 일부 결제 실패

11월 18일(수) 오후, 결제 페이지에 오류가 발생해 일부 고객이 결제를 완료하지 못했습니다. 현재는 정상화되었으며, 발생 경위와 후속 조치를 공유드립니다.

### 요약

| 항목 | 내용 |
|---|---|
| 발생 일시 | 2026년 11월 18일(수) 14:05 최초 신고 ~ 14:32 정상화 (신고 기준 약 27분) |
| 증상 | 결제 페이지 접속 시 오류(500 에러)가 발생해 결제 진행 불가 |
| 영향 | 결제 시도 약 1,200건 실패 (추정) |
| 매출 영향 | 집계 중 (확정되면 추가 공유) |
| 원인 | 11/17(화) 배포된 쿠폰 기능의 결함 |
| 조치 | 쿠폰 기능 배포 이전 버전으로 되돌림(롤백) |
| 현재 상태 | 정상 운영 중 |

### 경과

| 시각 | 내용 |
|---|---|
| 14:05 | CS팀에서 결제 페이지 오류 신고 접수 |
| 14:12 | 원인 확인: 전날 배포된 쿠폰 기능 |
| 14:30 | 쿠폰 기능 배포 이전 버전으로 롤백 |
| 14:32 | 결제 정상 동작 확인 |

### 원인

11월 17일(화)에 배포된 쿠폰 기능에 결함이 있었습니다. 쿠폰을 사용하지 않는 주문을 처리할 때, 존재하지 않는 쿠폰 정보를 읽으려다 오류가 나는 문제였습니다. 이 때문에 쿠폰 없이 결제하려던 주문이 실패했습니다.

배포 전 테스트에서 '쿠폰을 쓰지 않는 주문' 경우가 확인되지 않아 문제를 미리 발견하지 못했습니다.

### 영향

- 결제 시도 약 1,200건이 실패한 것으로 추정됩니다.
- 매출 영향은 아직 집계 중이며, 확정되는 대로 이 채널에 추가로 공유드리겠습니다.
