PR 설명을 다듬었습니다. 원본 `pr-draft.md`는 그대로 두고 `pr-description.md`로 따로 저장했습니다.

```markdown
## 배경

대량 발송 때 알림 큐가 밀려서 발송이 늦어지는 문제가 있었습니다.

## 변경 사항

- 알림을 100건씩 배치로 묶어서 보내도록 변경
- 발송 워커 수를 4개에서 8개로 증설
- 모니터링 대시보드 개선

## 기대 효과

큐 적체가 줄어서 대량 발송 시 지연이 대부분 해소될 것으로 봅니다.

## 리뷰 요청

배치 크기(100건)와 워커 수(8개)가 적절한지 같이 봐주세요.
```

**바꾼 것**
- 한 문단에 다 들어 있던 내용을 배경, 변경 사항, 기대 효과, 리뷰 요청으로 나눴습니다. 변경 사항은 목록으로 정리했습니다.
- "본 PR은 ~을 포함하고 있습니다", "~이 이루어졌습니다", "해당 변경을 통해", "또한 이와 관련하여" 같은 딱딱한 번역투와 피동형을 빼고 짧게 썼습니다.
- 알려주신 숫자(100건 배치, 워커 4개에서 8개)를 넣어서 "배치 처리 방식 도입", "워커 수 조정"처럼 흐릿하던 부분을 구체적으로 바꿨습니다.
- 원문의 "추가 검토가 필요한 부분이 있을 수 있으니 참고 부탁드립니다"는 무엇을 봐달라는 건지 알 수 없어서, 이번 변경에서 가장 판단이 필요해 보이는 배치 크기와 워커 수를 봐달라는 요청으로 바꿨습니다. 실제로 봐줬으면 하는 부분이 따로 있으면 그걸로 바꿔 주세요.

**채워 주시면 좋은 것**
- **대시보드:** 원문에 "개선"이라고만 있어서 저도 그대로 뒀습니다. 지표를 추가했다거나 패널을 바꿨다거나 하는 내용을 한 줄 적어 주시면 리뷰하는 분이 이해하기 쉽습니다.
- **기대 효과:** 지금은 추정으로만 적혀 있습니다. 부하 테스트나 스테이징에서 측정한 수치(예: 발송 소요 시간이 몇 분에서 몇 분으로 줄었는지)가 있으면 넣는 게 설득력이 훨씬 좋습니다.
