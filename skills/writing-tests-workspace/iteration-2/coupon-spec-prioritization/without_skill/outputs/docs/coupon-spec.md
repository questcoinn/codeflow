# 쿠폰 스펙

1. 통화 코드는 KRW이다.
2. 주문 금액이 10,000원 미만이면 쿠폰을 적용하지 않는다.
3. 정률 쿠폰은 주문 금액의 비율만큼 할인한다. 원 단위 미만은 버린다.
4. 정액 쿠폰은 쿠폰 금액만큼 할인한다.
5. 최종 금액은 0원 미만이 될 수 없다.
6. 중복 불가 쿠폰은 다른 쿠폰과 함께 쓸 수 없고, 함께 쓰면 오류가 난다.
7. 총 할인액은 주문 금액의 50%를 넘을 수 없다.
8. 쿠폰 적용 시 INFO 로그를 남기며 문구는 "coupon applied"로 시작한다.
9. 로거 이름은 모듈 이름을 따른다.
